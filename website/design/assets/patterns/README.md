# Pattern screenshots — capture guide

Drop captured PNGs here using the exact filenames referenced in `../07-visual-pattern-library.md`
(e.g. `p01-intro-offer.png`). The doc already links these slots, so images render once added.

## How to capture (free)
- **Browser DevTools** (no install): open the reference URL → DevTools → Cmd/Ctrl+Shift+P →
  "Capture node screenshot" (element) or "Capture full size screenshot" (page).
- **Firefox**: right-click element → "Take Screenshot".
- **macOS** Shift+Cmd+4 / **Windows** Win+Shift+S for region grabs.
- Annotate with any free tool (Excalidraw, macOS Preview markup, Greenshot, Flameshot).

## Conventions
- Width ~1400px desktop; add `-mobile` suffix for 390px captures.
- Keep < 400 KB (export as optimised PNG/WebP).
- One pattern per file; annotate the specific element, not the whole page.
